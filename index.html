Calendar Widget

구글 캘린더와 연동되는 Windows 데스크톱 달력 앱입니다.

기능

  • 일·주·월·연·목록 보기와 이번 달 일정 목록
  • 일정 만들기·수정·삭제, 반복 일정, 드래그로 시간 옮기기
  • 여러 캘린더 색상 구분·표시/숨김, 검색과 필터
  • 일정 알림과 미루기, 구글 할 일(Tasks) 완료 체크·이월
  • 시간대 변환, 대한민국 공휴일, 음력 날짜, .ics 가져오기·내보내기

구글 계정 사용

이 앱은 사용자가 직접 구글 계정으로 로그인했을 때만 그 사용자의 구글 캘린더와 구글 할 일(Tasks)을 읽고 씁니다. 데이터는 사용자 PC의 앱과 구글 사이에서만 오가며, 별도의 서버로 보내지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.
